# Den ersten Chat starten

Diese Anleitung führt vom laufenden MatoLoop zum ersten Chat. Für Chat brauchst du keinen verbundenen Computer. Die Serverinstallation steht unter [Betrieb und Datensicherung](betrieb-und-datensicherung.md#erstinstallation).

## 1. Anmelden

Bei einer neuen Instanz erstellst du das erste Konto mit einem Passwort von mindestens zehn Zeichen. Es erhält Administratorrechte. Bei einer bereits eingerichteten Instanz meldest du dich mit dem vom Administrator angelegten Konto an.

## 2. Ein Chatmodell bereitstellen

Ist bereits ein Modell eingerichtet, gehe zu Schritt 3. Andernfalls richte es als Administrator ein:

1. Öffne **Administration > Provider > Verwaltung** und lege deinen Provider an.
2. Verbinde das Konto beziehungsweise trage Serveradresse und Zugangsdaten ein.
3. Synchronisiere die Modelle, aktiviere ein Chatmodell mit Tool-Unterstützung und teste die Verbindung.
4. Wähle es unter **Administration > Standardmodelle > Verwaltung** als Agentmodell und speichere.

Die benötigten Angaben je Anbieter stehen unter [Provider und Modelle](provider-und-modelle.md).

!!! warning "Datenübertragung"
    Der gewählte Anbieter erhält die für den Chat autorisierten Inhalte. Wähle die Einstufung und [Datenfreigaben](freigaben-und-datenfreigabe.md#vertrauenslevel-und-datenfreigabe) passend zu deinen Daten.

## 3. Eine Nachricht senden

1. Öffne **Home** oder eine neue Unterhaltung.
2. Wähle die Sessionvorlage **Allgemein**.
3. Gib beispielsweise „Erkläre mir kurz, wobei du helfen kannst“ ein und sende.

Die Unterhaltung wird gespeichert und die Antwort erscheint im Chat. Du findest sie anschließend in der Seitenleiste wieder.

## 4. Bei Bedarf eine Aktion freigeben

Benötigt ein Tool deine Zustimmung, zeigt MatoLoop die Aktion und ihren Geltungsbereich. Prüfe beides vor **Für diesen Lauf erlauben**, **Für Session erlauben** oder **Ablehnen**. Eine Freigabe kann weitere passende Aktionen abdecken; siehe [Freigaben prüfen](freigaben-und-datenfreigabe.md).
